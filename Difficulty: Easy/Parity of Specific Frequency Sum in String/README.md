<h2><a href="https://www.geeksforgeeks.org/problems/help-nobita0532/1">Parity of Specific Frequency Sum in String</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given a string <strong>s</strong> consisting of lowercase English letters, find if sum of two values x and y is even.</span></p><ul><li><span style="font-size: 18px;">x is the number of distinct characters that&nbsp;</span><span style="font-size: 18px;">are at even positions in the English alphabet (b, d, f, ...), and&nbsp;</span><span style="font-size: 18px;">appear even times in the string.</span></li><li><span style="font-size: 18px;">y is the number of distinct characters that </span><span style="font-size: 18px;">are at odd positions in the English alphabet (a, c, e, ...), and&nbsp;</span><span style="font-size: 18px;">appear odd&nbsp; times in the string.</span></li></ul><p><span style="font-size: 18px;">Return true if x + y is even; otherwise, return false.</span></p><p><strong style="font-size: 18px;">Examples:</strong></p><pre><span style="font-size: 18px;"><strong>Input: </strong>s = "abbbcc"
<strong>Output:</strong> false
<strong>Explanation: </strong>'a' occupies 1st place(odd) in English alphabets and its frequency is odd(1), 'b' occupies 2nd place(even) but its frequency is odd(3) so it doesn't get counted and 'c' occupies 3rd place(odd) but its frequency is even(2) so it also doesn't get counted. x = 0 and y = 1 so (x + y) is ODD, Hence we return false. 
</span></pre><pre><span style="font-size: 18px;"><strong>Input: </strong>s = "nobitaa"
<strong>Output:</strong> true
<strong>Explanation:</strong> Here n, b, t &amp; a would not count since it doesn't match with the even condition but o &amp; i will be counted as it satisfies the odd conditions so x = 0 and y = 2 so (x + y) is EVEN, Hence we return true.
