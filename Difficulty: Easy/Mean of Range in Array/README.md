<h2><a href="https://www.geeksforgeeks.org/problems/mean-of-range-in-array2123/1">Mean of Range in Array</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given an integer array <strong>arr[]</strong> and a 2D array <strong>queries[][] </strong>of size <strong>q</strong>. Each query queries[i] = [l, r] represents a subarray ranging from index l to r (inclusive). </span><span style="font-size: 18px;">For every query, compute the mean (average) of the elements in the specified range, and return the floor value of that mean.</span></p>
<p><span style="font-size: 18px;">Return an array where each element corresponds to the result of a query.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> arr[] = [1, 2, 3, 4, 5], <span style="font-size: 14pt;"><span style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif; white-space-collapse: collapse;">queries</span>[][] = [[0, 2], [1, 3], [0, 4]]</span><br><strong>Output:</strong> [2, 3, 3]<br><strong>Explanation:</strong> </span><span style="font-size: 18px;">The array is [1, 2, 3, 4, 5].<br></span><span style="font-size: 18px;">Query 1: l = 0, r = 2 -&gt; subarray [1, 2, 3] -&gt; sum = 6 -&gt; mean = 6/3 = 2<br></span><span style="font-size: 18px;">Query 2: l = 1, r = 3 -&gt; subarray [2, 3, 4] -&gt; sum = 9 -&gt; mean = 9/3 = 3<br></span><span style="font-size: 18px;">Query 3: l = 0, r = 4 -&gt; subarray [1, 2, 3, 4, 5] -&gt; sum = 15 -&gt; mean = 15/5 = 3<br>Hence the answer is [2, 3, 3]</span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> arr[] = [6, 7, 8, 10], queries<span style="font-size: 14pt;">[][]</span> = [[0, 3], [1, 2]]<br><strong>Output:</strong> [7, 7]<br><strong>Explanation:</strong> The array is [6, 7, 8, 10].<br>Query 1: l = 0, r = 3 </span><span style="font-size: 18.6667px;">-&gt;</span><span style="font-size: 14pt;"><span style="font-size: 14pt;"> subarray [6, 7, 8, 10] -&gt; sum = 31 -&gt; mean = 31/4 = 7 (floor value)<br></span><span style="font-size: 18.6667px;">Query 1: l = 1, r = 2 -&gt; subarray [7, 8] -&gt; sum = 15 -&gt; mean = 15/2 = 7 (floor value)<br>Hence the answer is [7, 7]</span></span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong>&nbsp;<br>1 ≤ arr.size() ≤ 10<sup>5</sup><br>1 ≤ arr[i] ≤ 10<sup>3<br></sup>1 ≤ q ≤ 10<sup>5</sup><br>0 ≤ queries[i][0] </span><span style="font-size: 18px;">≤</span><span style="font-size: 18px;">&nbsp;</span><span style="font-size: 18px;">queries[i][1]</span><span style="font-size: 18px;"> &lt; arr.size()</span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Prefix Sum</code>&nbsp;<code>Arrays</code>&nbsp;
