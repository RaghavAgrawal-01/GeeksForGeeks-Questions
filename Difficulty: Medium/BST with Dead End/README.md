<h2><a href="https://www.geeksforgeeks.org/problems/check-whether-bst-contains-dead-end/1">BST with Dead End</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p data-start="101" data-end="197"><span style="font-size: 14pt;">Given a <strong>root</strong> of Binary Search Tree (BST) containing unique positive integers greater than 0. F</span><span style="font-size: 14pt;">ind if the BST contains a dead end. </span><span style="font-size: 14pt;">A dead end is a leaf node in the BST such that no new node can be inserted in the BST at or below this node while maintaining the BST property and the constraint that all node values must be &gt; 0.</span></p>
<p><strong><span style="font-size: 20px;">Examples:</span></strong></p>
<pre><span style="font-size: 20px;"><strong>Input: </strong>root[] = [8, 5, 9, 2, 7, N, N, 1]</span><br><span style="font-size: 20px;"><strong><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/700425/Web/Other/blobid1_1748007119.webp" width="205" height="199"></strong></span><br><span style="font-size: 20px;"><strong>Output: </strong>true
<strong>Explanation: </strong>Node 1 is a Dead End. We can neither insert 0 as only positives are allowed nor insert 3 (because 3 cannot be inserted as left of 2)</span></pre>
<pre><span style="font-size: 20px;"><strong>Input:</strong> root[] = [8, 7, 10, 2, N, 9, 13]<strong><br></strong><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/700425/Web/Other/blobid3_1748007366.webp" width="208" height="156"></span><br><span style="font-size: 20px;"><strong>Output:</strong> true
<strong>Explanation: </strong>Node 9 is a Dead End in the given BST.</span></pre>
