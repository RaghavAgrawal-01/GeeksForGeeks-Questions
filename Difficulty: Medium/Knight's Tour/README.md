<h2><a href="https://www.geeksforgeeks.org/problems/the-knights-tour-problem/1">Knight's Tour</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p data-pm-slice="1 1 []"><span style="font-size: 14pt;">Given an integer <strong>n</strong>, representing the size of an n × n chessboard. A </span><span style="font-size: 14pt;">Knight moves two cells in one direction and one cell perpendicular to that direction. </span></p><ul><li data-pm-slice="1 1 []"><span style="font-size: 14pt;">Knight starts at the top-left corner (0, 0) of the board. </span></li><li data-pm-slice="1 1 []"><span style="font-size: 14pt;">Your task is to find a valid tour, in which the Knight visits every cell of the board exactly once.&nbsp;</span><span style="font-size: 14pt;">Return an n × n matrix in which each cell contains the order in which it is visited.&nbsp;</span></li><li><span style="font-size: 14pt;">If a valid tour does not exist, return an empty list. &nbsp;</span></li><li><span style="font-size: 14pt;">There can be multiple valid tours, you may return any one.</span></li></ul><p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p><pre><span style="font-size: 14pt;"><strong>Input:</strong> n = 5
<strong>Output: <br></strong></span><span style="font-size: 14pt;">[[0, 11, 2, 17, 20],<strong><br></strong>[3, 16, 19, 12, 7],<br>[10, 1, 6, 21, 18],<br>[15, 4, 23, 8, 13],<br>[24, 9, 14, 5, 22]]
<strong>Explanation:</strong> A possible knight's tour in a 5 x 5 chessboard is given above where each number represents the step at which the Knight visits that cell, starting from (0, 0) as step 0.
</span></pre><pre><span style="font-size: 14pt;"><strong>Input:</strong> n = 4
<strong>Output: </strong>[]
<strong>Explanation:</strong> For n = 4, no sequence of knight moves can visit all 16 cells exactly once, starting from the top-left cell. Hence, the answer is an empty array [].</span></pre></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Recursion</code>&nbsp;<code>Backtracking</code>&nbsp;<code>Puzzles</code>&nbsp;
