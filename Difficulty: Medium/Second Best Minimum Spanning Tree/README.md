<h2><a href="https://www.geeksforgeeks.org/problems/second-best-minimum-spanning-tree/1">Second Best Minimum Spanning Tree</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given an <strong>undirected graph</strong> of <strong>V</strong> vertices numbered from (0 to V-1) and <strong>E</strong> edges represented by a 2D array <strong>edges[][]</strong>, where each <strong>edges[i]</strong> contains three integers <strong>[u, v, w]</strong>, representing an undirected edge from <strong>u</strong> to <strong>v</strong>, having weight <strong>w</strong>.</span></p>
<p><span style="font-size: 14pt;">Find the weight of the<strong> second best minimum </strong>spanning tree of the given graph. If no such second best MST exists, return -1. .</span></p>
<p><span style="font-size: 14pt;">A second best MST is defined as the minimum-weight spanning tree whose total weight is strictly greater than the weight of the minimum spanning tree.</span></p>
<p><span style="font-size: 14pt;"><strong>Note:</strong> The graph is connected and does not contain any self-loops or parallel (multiple) edges.</span></p>
