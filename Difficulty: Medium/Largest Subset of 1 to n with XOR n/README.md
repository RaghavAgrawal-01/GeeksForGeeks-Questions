<h2><a href="https://www.geeksforgeeks.org/problems/subset-xor--175953/1">Largest Subset of 1 to n with XOR n</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p class="PDq2pG_selectionAnchorContainer" dir="auto" data-start="436" data-end="570"><span style="font-size: 14pt;">Given a positive integer <strong data-start="461" data-end="466">n</strong>, select a subset of numbers from 1 to n, where each number can be selected at most once, such that:</span></p><ul data-start="572" data-end="771"><li data-section-id="1vz3bcx" data-start="572" data-end="621"><span style="font-size: 14pt;"> The XOR of all selected numbers is exactly n. </span></li><li data-section-id="194evqj" data-start="622" data-end="680"><span style="font-size: 14pt;"> The number of selected elements is as large as possible. </span></li><li data-section-id="125q230" data-start="681" data-end="771"><span style="font-size: 14pt;"> If multiple subsets have the maximum size, return the lexicographically smallest subset. </span></li></ul><p dir="ltr" style="box-sizing: border-box; margin: 0px 0px 10px; padding: 0px; border: 0px; font-size: 18px; vertical-align: baseline; color: #273239; font-family: Nunito, sans-serif; letter-spacing: 0.162px; background-color: #ffffff;"><span style="font-size: 14pt;"> </span></p><p dir="auto" data-start="773" data-end="1049"><span style="font-size: 14pt;">The subset should be returned in increasing order. A subset a[] is lexicographically smaller than subset b[] if, at the first position where they differ, a[i] &lt; b[i]. If one subset is a prefix of the other, the shorter subset is considered lexicographically smaller.</span></p><p><span style="font-size: 18px;"><strong>Examples:</strong></span></p><pre><span style="font-size: 18px;"><strong>Input: </strong>n = 4<br><strong>Output: </strong>[1, 2, 3, 4]</span><span style="font-size: 18px;"><br><strong>Explanation:</strong> 1 ^ 2 ^ 3 ^ 4 = 4, so all numbers can be selected. This gives the maximum possible subset size.</span></pre><pre><span style="font-size: 18px;"><strong>Input: </strong>n = 3<br><strong>Output:</strong> [1, 2]<br><strong>Explanation:</strong> 1 ^ 2 = 3. Selecting all three numbers gives 1 ^ 2 ^ 3 = 0, so the maximum valid subset contains two elements.</span></pre></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Bit Magic</code>&nbsp;<code>Mathematics</code>&nbsp;<code>Arrays</code>&nbsp;
